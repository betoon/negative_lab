# Changelog

## 0.4.1 — Light Table Workflow

- Upgraded the Virtual Light Table with persistent ratings, color labels,
  rejection flags, notes, and direct return to the selected frame.
- Added editable RGB curve control points and clearer per-frame mask management.
- Improved handling when a damaged or missing frame cannot be rendered in the
  Light Table.

## 0.4.0 — Digital Darkroom

- Added the Virtual Light Table and exportable contact sheets.
- Added fine rotation, perspective rectification, curves, and clipping overlays.
- Added reusable radial/gradient mask, healing, and cloning engines.
- Added automatic anchor discovery and roll-wide consistency analysis.
- Added infrared cleanup and aligned multi-exposure scan fusion.
- Added archival manifests, Film Character Designer, and Camera-Scanning Assistant.

## 0.3.0 — Performance and Release Operations

- Added full-resolution memory estimates and available-RAM warnings.
- Added configurable OpenCV CPU threads and honest OpenCL availability reporting.
- Added disk-backed calibrated-preview caching.
- Added archival, web, proof, and custom output configurations.
- Added resize, overwrite protection, and configurable failed-frame recovery.
- Added periodic recovery projects, recent projects, and drag-and-drop import.
- Added processing history and privacy-labeled diagnostic ZIP packages.
- Hardened the portable build for installations without optional RAW support.

## 0.2.0 — Calibration and Restoration

- Added matching dark-frame and flat-field correction.
- Added matrix JSON, matrix-only DCP, and paired-RGB IT8 calibration.
- Added sRGB and custom ICC output handling with embedded profiles and DPI.
- Added fading, dust, sprocket/holder, and local adjustment tools.
- Added film-profile comparison and aligned trichrome construction.
- Expanded diagnostics, persistence, tests, and manuals.

## 0.1.0 — Foundation

- Added roll projects and session persistence.
- Added linear conventional and optional RAW input.
- Added robust clear-base and dense-leader sampling.
- Added two-point logarithmic density conversion and film profiles.
- Added PhotoLab-style conversion preview and per-frame recipes.
- Added selective synchronization, automatic framing, and batch conversion.
- Added anchor, frame, batch, and system diagnostics.
- Added tests, user/developer manuals, and a Windows portable-build script.
